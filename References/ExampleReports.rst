Example Reports
###############

The best way to see OSVVM's reports is to look at them in HTML form. As you examine them, read
:ref:`Regression Testing and Reports <RPT>`, which explains the important aspects of each report.

   :widths: 60 40
   :header-rows: 1

   * - Report
     - Link
   * - Latest regression of OsvvmLibraries on ``main``, NVC on Ubuntu (updated with every documentation build).
     - `Build index <../regression/index.html>`__
   * - Run of ``OsvvmLibraries/RunAllTestsWithCoverage.pro`` with Aldec Riviera-PRO, including code coverage (2024).
     - `OsvvmLibraries_RunAllTestsWithCoverage.html <../_static/riviera/OsvvmLibraries_RunAllTestsWithCoverage.html>`__
   * - Test cases with failures, Siemens QuestaSim 2023.10 (2024). How long does it take you to find which test cases
       fail? You can also find the failures in the HTML simulator transcript (log).
     - `OsvvmLibraries_RunErrorTestsWithCoverage.html <../_static/questa/OsvvmLibraries_RunErrorTestsWithCoverage.html>`__
   * - Coverage of the public and private OSVVM test suites, hosted by SynthWorks.
     - `sim_RunAllTestsWithCov.html <https://synthworks.com/papers/riviera/sim_RunAllTestsWithCov.html>`__
   * - Alternately, create your own.
